# Agent Skills — deferred (identity unresolved)

**Decision:** Deferred. Neither installed nor adopted. Do not install until the
intended project is named.

## Why deferred

“Agent Skills” is an ambiguous name. It may refer to:

- the Agent Skills specification (`agentskills/agentskills`);
- Anthropic's skills collection (`anthropics/skills`);
- Vercel's installer collection (`vercel-labs/agent-skills`), whose licence is
  missing and which is an installer ecosystem rather than a workflow.

These are different projects with different licences and install methods. A
publish name alone is insufficient to identify software to install.

## Related entries

- Anthropic Skills: `integrations/anthropic-skills.md`
- Agent Skills spec: reference only — `agentskills/agentskills`, licence to be
  confirmed
- Vercel agent-skills: not adopted — installer ecosystem

## If adopted later

Name the exact repository, the publisher, and the install mechanism in a
re-verification entry. Record the canonical URL, the licence as published by
the repository (not the badge), recent activity, a tested version, and proof
that the workflow was exercised. Update this file and §21.2 of the master
document.
